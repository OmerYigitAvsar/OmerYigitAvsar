## Featured Projects

### [Geometry Kingdom](https://github.com/OmerYigitAvsar/geometry-kingdom)

A 2D fantasy tower defense game built with Unity for Android and WebGL. Players defend a crystal kingdom through enemy waves by placing towers, setting targeting priorities, and upgrading tower types. A leaderboard tracks each player's best wave.

[Play Geometry Kingdom in your browser](https://mergithgamestudio.netlify.app/Games/GeometryKingdom/play.html)

### [The Troll Game (Sinir Bozucu)](https://github.com/OmerYigitAvsar/the-troll-game)

A 2D Unity platformer with traps that change platforms, reverse controls, or alter gravity. The project includes variable-height jumping with coyote time and input buffering, reusable trap triggers, and a custom Unity Editor tool for building levels.
